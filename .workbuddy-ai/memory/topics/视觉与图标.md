# 视觉系统（液态玻璃）· 图标

> 从 `MEMORY.md` 拆出。改 `web/css/style.css`、`web/js/widgets/icons.js`、
> `tools/make_icons.mjs` 之前先读完本文。

## 一、液态玻璃视觉系统（改样式前必读）

**零依赖**：全靠 CSS `backdrop-filter`，不引任何图片/库/构建步骤。
令牌清单见 `web/css/style.css` 的 `:root` 与 README「v1.6.0 视觉改版」——
**改样式前先读那里，不要凭印象写变量名**（写错的变量不报错，只是样式静默失效）。

三条硬约束：

1. **玻璃元素自身背景必须半透明**（`rgba`）。写成 `#fff` 则 `backdrop-filter` 无从体现。
2. **`.bottom-nav` 的 `--nav-h` 仍是布局基准**（`.app-body` 底部留白按它算），
   但 dock 视觉高度是 66px 且 `bottom: 8px` 浮起 —— 改 nav 高度要同时照顾两处。
3. **`prefers-reduced-motion` 与 `env(safe-area-inset-bottom)` 必须保留**。

🔴 **悬浮按钮的负 margin**：`.bottom-nav__fab` 跨出 dock 上沿时，
**`align-self: center` 配负 `margin-top` 会被 flex 剩余空间吃掉**（写 -24px 实测只浮 9px）。
**必须 `align-self: flex-start` + 负 margin**。
当前：dock 66 / 按钮 58 / `margin-top: -20px` → 实测跨出 **19px**。
`tools/verify_glass.mjs` 有断言守着这个几何关系，改动后跑一下。

## 二、底部导航激活态（v1.10.0：整块填充）

**不用小圆点**。当前页的图标换成**实心字形**，整个图形被品牌蓝填满。

- 每个导航项渲染**两个字形**（`.bottom-nav__ico--line` / `--fill`）叠在同一位置
  （`grid-area: 1/1`），由 CSS 按 `--active` 交叉淡入淡出
  —— 比运行时换 `html` 少一次重排，还自带过渡。
- 实心版在 `icons.js`：`calendarSolid` / `recordSolid`，用 `fill-rule="evenodd"`
  挖内部镂空（日历 2 个日期点、记录的对勾）。**只服务底部导航**，
  其他位置一律用描边版 `calendar` / `record`。
- 🔴 **填充色写 `currentColor`，不要硬编码蓝色** —— 这样父级 `color` 的过渡
  能同时驱动「图标填充」和「文字变色」，两者永远一致。
- **新增导航项时必须一并加实心版**，否则激活时该图标会变成空白。
- 回归：`node tools/verify_nav_icon.mjs`（25 项）。

## 三、图标生成

`tools/make_icons.mjs`，**零依赖**（PNG 用 Node 自带 `zlib` 手写编码）。
**混合策略**：大尺寸用 3D 黏土版源图；小尺寸用扁平矢量 SDF 版 ——
3D 版缩到 16px 会糊成一团蓝。细节与完整踩坑史见 README「v1.7.1」「v1.8.1」两节。

**四种渲染模式**（`renderFrom3D` 的 job 参数）：

| 模式 | 用在哪 | 特点 |
|---|---|---|
| 默认（`maskable:false`） | icon-192 / icon-512 | 圆角裁切，**四角透明**，留 4% 内边距 |
| `maskable:true` | icon-maskable-512 | 满幅不透明，安全区 14%，作品边缘色铺底 |
| `cover:true` | apple-touch-icon | 满幅不透明，**放大溢出**让圆角落到画布外 |
| `tiny`（size<48，函数内自动） | favicon 32 / 16 | 白纸 + 蓝表头 + 粗勾，只留三个形状 |

🔴 **apple-touch-icon 必须满幅不透明** —— **iOS 会把透明像素合成成黑色**，
带透明圆角的图标装到 iPhone 桌面上四个角就是四块黑。浏览器里完全看不出来。
这一版**不能**用 maskable 的「铺底」做法：安全区一小，铺底就会露成一圈「边框」
（实测过 9% 安全区，肉眼可见）。用 `cover`（放大到 1.21×）——
画布上每个像素都来自作品本身，**接缝在原理上就不可能存在**，也不需要配色。

🔴 **favicon 16/32 不能沿用 48 那套等比缩小**：日期格只剩 2.5px、勾的笔画只剩
0.36px（亚像素），渲染出来是一团蓝白色的糊。极简版每根笔画 ≥1.5px。

🔴 **极简版的表头不能贴着白纸的上沿**：贴沿时它和图标外圈的蓝底直接连成一片
（16px 下实测 y=0..4 整五行全蓝），「日历」这个线索就没了，只剩一块白卡片加一个勾。
**必须留一道白缝**（`barGap = max(1, size*0.07)`）把纸的上沿描出来。
> 白缝在 16px 下只有 1 行、32px 下有 2 行 —— 写断言时别假定它只有一行。

**改图标前必看的四条**（都是踩过的）：

1. **圆角半径必须实测，不能硬编码**（硬编码会啃进蓝色、四角出现透明缺口）。
2. **内容边界必须外扩 `side * 0.022`**（3D 稿边缘是柔和渐变，探到的边界在真实边缘内侧）。
3. **maskable 不能「缩小贴一份」**（缩 → 白描边环；铺满 → 白方块）。
   先用作品自身的蓝铺满画布，再把作品**圆角裁切**后贴到安全区。
4. **普通版也要留 4% 内边距**（有些启动器对任何图标都套圆形遮罩）。
   > maskable 正常**不代表**普通版安全，**必须分别套真实遮罩看**。

SDF 注意：**描边用 `sdRoundRectStroke`**（「大矩形减小矩形」在圆角处有月牙缺口）；
**胶囊形用「两端点 + 半径」定义**（用长度算式相减会算出负长度、缩成小凸起）。

### 改完必须跑的两个检查

- `node tools/verify_icons.mjs`（42 项）—— 钉住「重新生成一次就可能悄悄退化」的硬约束：
  文件齐全与尺寸、apple-touch-icon 与 maskable **整幅不透明**、192/512 四角透明、
  16/32 的白纸/白缝/表头/勾四要素、index.html 与 manifest 的引用一致性。
  > 已做过**负向测试**：把表头改回贴沿，这个脚本会红。
- `node tools/zoom_icons.mjs` —— 肉眼复查（产出 `tools/_zoom_icons.png`）。
  小尺寸 PNG 之间的差异在正常尺寸下看不出来，`Read` 又会把相似的图判成「未变化」。
