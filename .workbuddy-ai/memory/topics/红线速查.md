## 🔴 红线速查（展开原文 → `topics/红线全文.md`）

1. **零依赖、零构建**；正则集中 `web/js/utils/regex_patterns.js`，禁止写死。
2. **数据全在本地、零上传**；**IndexedDB 按 origin 隔离**（`localhost` 与局域网 IP 是两套数据）。
3. **库名 `campus_week_calendar` 与 sw 前缀 `campus-week-` 永不改名**（改名丢数据）。门面叫「周周记」，旧名「校园活动周历」是**有意保留的副标题**。
4. **改 `web/` 后必须升 `package.json` version + `npm run pwa`**，否则手机吃旧缓存。
5. **改布局后必须跑 E2E 第 12 组**（单元测试发现不了布局问题）。
6. **文件被对方删除/重组 → 立刻停手报告**，不要重建、不要争同一文件。
7. **测试期望值改到第三次不收敛 → 先怀疑模型**；写独立真值表钉死期望再改实现。
8. **写 CSS 前先核对 `:root` 令牌名** —— 写错的变量不报错、只静默失效。
9. **加原生插件后必须看 APK 体积**（Gradle 默认打四种 CPU 架构的 `.so`，翻四倍）。已 `abiFilters` 限到 ARM 两套，代价是**装不进 x86 模拟器**。
10. **通知图标只取 alpha 且必须放 `drawable-*`**（mipmap 会静默回退成系统图标）；**apple-touch-icon 必须满幅不透明**。跑 `verify:icons`。
11. **签名密钥 + 密码丢了 = 永远无法更新应用**；备份在项目外 `D:\desktop\周周记-签名密钥备份\`（**仍未拷到机器外**）。
12. **清 `kv` 表必须用 `DatabaseService.removeSetting(key)`** —— `_remove()` 把键转 `Number`，字符串键成 `NaN` → `DataError`。
13. **关浮层的 dismiss 必须走各自的正常取消路径**，绝不能 `overlay.remove()` —— 背后 `await` 的 Promise 永不 resolve，调用方静默挂死。
14. **`touch-action` 不继承**，横滑手势要在容器**和子元素**上各写一次；**只有 touch 事件能 `preventDefault()`**，「先定轴再拦截」必须用 touch 而非 pointer。
15. **`scroll-behavior: smooth` 下不能 `sleep(固定值)` 再断言滚动位置** —— 轮询 `scrollTop` 稳定；写死日期的 E2E 也要显式翻到目标周。
16. **更新不需要卸载**：包名 + 签名相同 + `versionCode` 递增 → 覆盖安装、数据保留。唯一要卸载的是「debug → release」那一次。
17. **卸载会删 IndexedDB 与 localStorage，但删不掉「文档」目录的自动备份**。判空**必须用 `DatabaseService.isEmpty()`**，不能用只数 events 表的 `count()`。
18. **UI 文案默认不解释词义**；只有真状态/警告才加字，视觉层级靠**字号与留白**拉开。
19. **版本号只在 `package.json` 写一次**，其余落点全由 `npm run pwa` 生成（`version.js`、`sw.js` 的 `VERSION`、安卓 `versionName`/`versionCode`）。`verify:pwa` 钉住。
20. **调小「两行小字」的卡片，先看行高再看 padding**：默认 `line-height ≈ 1.6`，只减 padding 顶多收 20%，钉 `line-height: 1.25` 才收得住。
21. **删 UI 元素前先 grep 它的 onclick 指向的函数还有没有别的调用点**；数据仍参与计算时必须留入口，否则变成「看不见、改不动、但一直在算」的幽灵数字。
22. **console 错误的来源看 `m.location().url`，不要只看 `m.text()`**（资源加载失败永远是同一句 `Failed to load resource`）。
23. **算「元素在滚动容器里的位置」不能用 `offsetTop`**（相对 offsetParent，会多算头部/筛选条）。用 `getBoundingClientRect().top - 容器.top + 容器.scrollTop`。
24. **把元素从「默认可见」改成「默认隐藏」前先 grep 谁依赖它可见**；区分**走 UI 创建**（有自动展开）与**直接调 API 播种**（没有）。
25. **`promptDialog` 返回值是「三态」不是布尔**：`null` 取消 / `''` **明确留空** / 其它填了。只拦取消写 `if (x === null) return;`；**必填用 `required: true`**。⚠️ 数值型留空 → `Number('')` = **0**，会把余额/净资产**悄悄清零**。
26. **用户手输日期只认一种格式是 bug**：统一走 `parseDateInput()`（放行 `-` `/` `.` `年月日`），正则用 `PATTERNS.DATE_INPUT`（**锚定首尾**）。🔴 **必须回读校验**：`2026-02-31` 合规但会被 `new Date` **静默滚到 3 月 3 日**。
27. **`toast()` 永远不许渲染成空 / `undefined` / `[object Object]`**：`err.message` 不保证是字符串（Capacitor 插件与 `DOMException` 抛的不是 Error）。🔴 拒绝值**不能**直接 `String(reason)`。
28. **异步点击处理器抛错必须有人兜**（界面大量 `onclick: async () => {}`，抛错时**界面什么都不发生**）。`main.js` 有 `unhandledrejection` + `error` 两个全局兜底；`error` 要过滤资源加载失败（`e.target !== window`）。
29. **测全局兜底处理器必须用「同源内联脚本」抛错，不能用 `page.evaluate`**（Chrome 当它另一个源 → 错误被**脱敏** → **假阴性**）。
30. **产品方向：功能齐全 > 新手友好**；别为「新手不迷路」砍功能或加解释文案。⚠️ 但「说明页」是用户主动打开的，那里该写清楚。
31. **自定义键盘用 `inputmode="none"` 压掉系统键盘，但别把 `<input>` 换成 `div`**（真输入框才能被物理键盘 / `page.type()` 驱动）。🔴 按键**绝不能**触发整页 `render()`（丢焦点）；键盘格用**显式 `gridArea`**。
32. **「让表单底部可见」不要靠底部撑高 spacer**（反效果）。⚠️ v1.13.5 起「记一笔」已是 fixed 浮层，对它作废（见 37）。正解：算 `topInRoot`，`scrollTop = min(topInRoot - 8, max)`。
33. **给模型加字段后必须检查 `normalizeXxx()` 的字段白名单**（常写成「手挑几个字段返回新对象」，新字段被**静默丢掉**，且只在「存一次再读一次」后现形）。补 `fromRecord(toRecord())` 往返断言。另：`entries` 按日期排序，别 `push` 后取 `at(-1)`。
34. **`LedgerEntry.account_id` 语义是「这行从账户页镜像过来」，不是挂账字段**。🔴 **两套字段不对称**：记账页挂账户 → 在**账户流水**的 `ledgerId`；账户页镜像到记账 → 在**记账行**的 `accountId` + `accountEntryId`。删除顺序**先撤挂账再删记账**。
35. **`LedgerEntry.direction` 只认 `'expense'` / `'income'`**，写别的会**静默归到支出**。⚠️ 别一刀切全局替换：`Loan` 那套**确实**是 `'in'` / `'out'`。
36. **金额两种格式别混用**：`money()` → `¥1,234.50`（要看清数额）；`amountShort()` / `signedAmount()` → `42.5` / `-42.5`（一屏几十个数字）。🔴 短格式**有损**，只能显示不能算（算术用 `round2()`）；🔴 `signedAmount(n, isExpense)` 的符号来自**第二个参数**。
37. **「记一笔」是 `position: fixed` 底部浮层**（`ledger_view.js`）。🔴 `pushOverlay()` 登记、dismiss 走 `cancelForm()`（见 13）；Esc 调 `dismissTopOverlay()`；`openSheet()` 要 `const keep = draft`；`openForm` 是 async，用 `formSeq` 作废抢跑。
38. **有「两道保险」的地方，测试要各补一条「只经过其中一道」的用例**。👉 通用纪律：**改坏 → 确认变红 → 改回**，只跑绿不算数。
39. **高度尺子用 `dvh` 不用 `vh`**（`vh` 量**大视口**，地址栏一露浮层顶被顶出屏幕，且 `scrollHeight == clientHeight` → **滚都滚不到**）。写法**旧值在前、新值在后**。四处：`.led-form` / `.qsheet` / `.input--multiline` / `body`。⚠️ headless 里 `100dvh === 100vh` → **渲染断言是假绿**，只能读 CSS 源码。
40. **曲线平滑（Catmull-Rom → 贝塞尔）的控制点必须夹到绘图带内**（过冲 ≈ **相邻落差 / 6**，谷底会沉到基线以下）。🔴 负向验证的种子数据必须**够极端**，否则删掉 `clampY` 照样全绿。
41. **`scroll-behavior: smooth` 的容器里不要用坐标点击**（`page.click(sel)`）—— 坐标在动画开始前算好，会点空、表现为莫名超时。用 `page.evaluate(() => el.click())`。
42. **升级后手机要「刷新两次」才看到新版本** —— 回答「更新装上了没有」先讲这句。第 1 次由**旧 SW** 控制，第 2 次才是新版。⚠️ 别把用户引到「升级失败了」。
43. **流水列表「一天一组」**：组头报两组小计，**只有一边有就只报一边**。别退回「日期 → 方向」两级分组。`.led-day__head` 要 `flex-wrap: wrap`，「方向 + 数字」包成 `.led-day__sum`；组内**不按方向二次排序**。🔴 回归断言取数组元素一律用 `?.`（否则脚本**抛异常退出**，后面几十条一条不跑）。
44. **账户之间的转账不计入收入，一条都不进记账总账**。判据是账户流水的 **`linkedAccountId`**（**只有 `transfer()` 会写它**）。⚠️ 旧数据也要清（`purgeTransferLedgerMirrors()`，kv 标记 `..._v1137`）；**只删记账侧、绝不碰账户流水**，且**不能只看 `category === 'acct_in'`**（外部充值镜像也是这个分类）。⚠️ 单账户卡片的 `totalIn` **是对的、别动**；Σ 各账户的**概览合计**要用 `totalInExternal` / `totalOutExternal`。⚠️ **`dailyBurn()` 同口径**（求和与**区间**都要 `!isTransferLeg` 过滤）。净资产 / 对账差额**要**含转账。
45. **备份导入会重发所有账户 id，凡存「整数 id」的字段都要跟着重映射**：`checkin_logs.checkin_id`、`ledger.accountId`、**`accounts.entries[].linkedAccountId`**。漏了**不报错、只静默留半截账**。🔴 找不到对方时**保持原样、别清空**（该字段同时是 `isTransferLeg()` 判据）。⚠️ **必须用 `merge:true` 测**（替换模式旧 id 恰好还对得上，测不出来）。回归：`verify:backup` 第 2.5 节。
46. **底部悬浮 dock 的真实占位比 `--nav-h` 大**：dock 是 `bottom:8px + height:66px`，中央「＋」还向上**跨出 20px** → 真实占到 **94px**。滚动容器 `padding-bottom` 必须 >= `nav-h + 46px`，否则最后一个元素滚到底会被压住（账户页「账户明细」就这么被埋过）。⚠️ 断言要**同时**量「不重叠」与「留够呼吸空间（>= 24px）」—— 只把元素本身做大（换成卡片）能骗过前者。
47. **「定宽 + 数字」是换行陷阱**：`.acct-flow__date` 写 `width: 36px`，Windows 字体下 "10-10" 只有 31.95px 塞得进，手机上（字体更宽 / 字体放大）就折成两行、行高翻倍。**日期这类定长串一律 `white-space: nowrap` + 不定宽**。🔴 回归里**只按本机默认字体量「占几行」会假绿** —— 必须再放大一轮字号才抓得住。
48. **底部抽屉（`.sheet`）必须限高 + 只有列表滚动**：选项是 `.sheet` 直接子节点而它既无 `max-height` 也不滚动时，选项一多面板就长到屏幕外 —— 顶部被裁、**怎么滑都不动**。正解：`.sheet` 加 `display:flex; max-height: calc(100dvh - 28px)`，选项包进 `.sheet__list { flex:1 1 auto; min-height:0; overflow-y:auto }`，标题/说明/「取消」`flex-shrink: 0`。⚠️ 别顺手 `slice(0, 30)` 截断列表却把标题写成「共 N 笔」—— 后几笔会变成**看不到也删不掉**。
49. **写死日期的 E2E 会「馊」。** 记账页默认只看**本月**（`month = monthKey(new Date())`），把播种日期写死成 `2026-09-xx`，到了 10 月一条都看不见 —— 表现为脚本**崩在 `No element found for selector`** 或整片红，而**代码一行没改**。改成跟着当前月算。⚠️ `getLedgerByMonth` 只按月份前缀过滤、**没有上界**，用固定的 18/19/20 号安全。（2026-10-13 一次踩中 3 个脚本：`ledgerform` 崩 / `ledgerlist` 14 红 / `transfer` 3 红。）
50. **`scroll-behavior: smooth` 下「滚到底再量坐标」必须轮询 `scrollTop` 稳定**，不能 `wait(固定值)`。单跑够、14 个脚本连着跑就量到**动画中途** → 假红（实测 851/828，实际落位 796/828）。⚠️ **假红比假绿更费时间** —— 它会让人去查一个不存在的回归。
51. **解析子进程 / CLI 输出前先剥 ANSI 颜色码。** 重置码 `\x1b[0m` **自带数字 `0`**，会噎死 `全部通过[^0-9]{0,6}(\d+)项` 这类写法 —— 脚本明明全绿，汇总表却报「没认出总结行」。⚠️ 这些回归脚本**断言失败时也 `exit 0`**，`grep '✗'` 又会漏掉末尾的 `  · 项目名` 汇总列表 → **退出码和 grep 都不可信，只认总结行**。全量跑用 **`npm run verify:all`**（会解析总结行、脚本间留间隔、只对「没跑完」重试）。
